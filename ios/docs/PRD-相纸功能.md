> **实现备注**：本 App 已无远程 AI 步骤，最终产出由设备端 Vision 抠图生成。因此文中「AI 生成成功」在实现上等价于「Vision 抠出主体成功（`cutout != nil`）」：抠到主体才扣配额，未抠到主体（保留原图 + 提示）不扣。

## 1. 背景与目标

现在 App 的产出是一张**抠掉背景的模切贴纸**（die-cut sticker），掉进物理沙盒把玩；流程里那张「相纸」只是吐纸 / 显影动画的过场，最终并不保留成相纸形态。

「相纸功能」把相纸从纯动画道具升级为**一个有数量、有种类、可分享的核心资源**，由三块组成：

1. **每日配额（消耗）** —— 每个用户每天有 10 张免费相纸，拍一张消耗一张。
2. **相纸种类（含会员专属）** —— 多种相纸（不同边框 / 版式外观），部分为会员专属。
3. **带相纸分享** —— 把贴纸套上选定相纸，渲染成一张图片分享出去。

目标：在保持「纯本地、无后端、无账户、隐私优先」现状的前提下，引入轻度的资源 / 收集感与会员变现入口。**本功能完全在设备本地实现，不引入账户体系，也不依赖任何服务端。**

## 2. 名词定义

| 名词 | 含义 |
| --- | --- |
| 相纸（Paper / PaperStyle） | 套在最终产出外层的**边框 + 版式外观**（白边相框、纸纹、颜色、日期 / 装饰）。**只影响外观，不影响 AI 生成，也不影响沙盒物理。** |
| 配额（Quota） | 每个用户每天可生成的相纸数量。免费 10 张 / 天，会员无限。 |
| 消耗 | 一次成功的 AI 生成扣减一张配额。 |
| 会员（Membership） | 付费订阅用户，享相纸专属、无限配额、分享去水印等权益。 |

## 3. 关键决策（已确认）

| 议题 | 决策 |
| --- | --- |
| 后端 / 账户 | **纯本地，无后端、无账户**。配额记 UserDefaults，会员用本地标志 / StoreKit 订阅（StoreKit 收据校验本身在设备本地完成，不需要自建服务器）。 |
| 消耗时机 | **AI 生成成功才扣**；按快门不扣，AI 失败 / 报错不扣（退还）。 |
| 相纸种类区别 | **仅边框 / 版式外观**。不改 AI 风格、不改沙盒手感 / 音效。 |
| 选相纸时机 | **拍完后在结果页 / 分享时随意切换**，切换不额外消耗配额。 |
| 分享形式 | **生成相纸图片**（贴纸 + 相纸边框 + 日期，按需水印），走系统分享面板。 |
| 会员权益 | ① 解锁会员专属相纸；② 更多 / 无限配额；③ 分享去水印。 |

## 4. 用户故事

- 作为用户，我每天有 10 张免费相纸，能直观看到今天还剩几张。
- 作为用户，当配额用尽时，我能看到清晰提示，并被引导去开通会员或等明天。
- 作为用户，AI 生成失败时不该白白扣掉我的相纸。
- 作为用户，拍出贴纸后我能给它换不同的相纸（边框 / 版式），实时预览。
- 作为用户，会员专属相纸我能看到但点了会提示需要会员，引导我订阅。
- 作为用户，我能把「贴纸 + 相纸」渲染成一张好看的图片分享给朋友 / 存相册。
- 作为会员，我享无限配额、全部相纸、分享图无品牌水印。

## 5. 功能详述

### 5.1 每日配额（消耗）

- **额度**：免费用户 10 张 / 天；会员无限（实现上用一个很大的常量 / `Int.max` 表达，便于未来调参）。
- **重置**：按**设备本地时区**每日 00:00 重置。实现：记录 `lastResetDay`（`yyyy-MM-dd` 本地）+ `usedToday`；App 启动 / 回到前台时，若 `today != lastResetDay` 则 `usedToday = 0` 并更新 `lastResetDay`。
  - 已知局限：纯本地记账，配额可被「改系统时间 / 重装 App」绕过。本功能定位为轻度收集感而非强付费墙，接受此局限。
- **消耗与退还逻辑**：
  1. 按下快门前先检查 `remaining > 0`；若为 0 → 不进入拍摄流程，弹「今日相纸已用完」提示 + 会员引导。
  2. `remaining > 0` 时正常走拍摄 → AI 流程。
  3. **仅当 AI 生成成功**（拿到白底贴纸，进入显影）才 `usedToday += 1`。
  4. AI 失败 / 报错 / 用户中途取消 → 不扣。
  - 单屏单次拍摄，同一时刻只有一个生成在飞，无并发扣减问题。
- **剩余额度展示**：在相机主界面常驻一个轻量计数（如「今日剩余 7/10」），配额用尽时变为可点的会员引导入口。会员显示为「无限 / ∞」。

### 5.2 相纸种类（含会员专属）

- 相纸目录在**代码中定义**（与 `Palette.swift` 同思路的单一来源），不是用户数据，便于随版本增删。
- 每种相纸定义：`id`、中文名、是否会员专属、视觉参数（边框颜色 / 渐变、纸纹、日期排版、角标 / 装饰）。
- **初始清单（提案，待产品确认 / 调整）** —— 全部基于现有 Palette，避免任何拍立得商标元素（无彩虹条 / 无红快门）：

  **免费（3 种）**
  | id | 中文名 | 外观 |
  | --- | --- | --- |
  | `cream` | 经典奶油白 | 默认。纯奶油白厚边相框（`cream`），底部加宽留白，印日期。 |
  | `kraft` | 牛皮手帐 | 暖牛皮纸边框（`kraft`）+ 手写体日期，手帐质感。 |
  | `klein` | 克莱因蓝 | 签名克莱因蓝（`klein`）窄边框 + 奶油内衬。 |

  **会员专属（4 种）**
  | id | 中文名 | 外观 |
  | --- | --- | --- |
  | `amber-glow` | 琥珀暖光 | 暖琥珀（`amber`）渐变边框，柔光角。 |
  | `deep-sea` | 深海渐变 | `klein → kleinDeep` 双档蓝渐变边框。 |
  | `film-charcoal` | 炭灰胶片 | 深炭灰（`faceplate`）边框 + 35mm 胶片齿孔装饰（齿孔为通用胶片元素，非拍立得商标）。 |
  | `journal-washi` | 手帐胶带 | 奶油底 + 手写日期 + 仿和纸胶带角贴装饰。 |

- **默认相纸**：`cream`；并记住用户上次选择，下次默认沿用。
- **会员专属交互**：免费用户可在选择器里**看到**会员相纸（带锁标），点击 → 可临时预览套用效果，但**不能确认 / 分享**，弹会员引导。确认订阅后解锁。

### 5.3 相纸选择与套用

- 入口：**结果页**（显影完成后的展示页）提供相纸选择器（横向滑动的缩略图条）。
- 切换实时预览，套用在最终产出上；**不消耗配额**。
- 选中的相纸 id 跟随该作品记录持久化（见 §6），历史 / 重新分享时沿用。
- 相纸只是外观层：沙盒里掉落的仍是抠图贴纸本身，**相纸不进沙盒、不改物理 / 音效**。

### 5.4 带相纸分享

- 入口：结果页 / 历史详情的「分享」按钮。
- 渲染：把贴纸（`PhotoRecord.displayImage`，即抠图优先）**居中合成到选定相纸边框上**，加日期，按会员状态决定是否加品牌水印，导出为一张 `UIImage`。
- 输出：走系统分享面板（`UIActivityViewController`）→ 微信 / 存相册 / 其他。
- **水印**：免费用户分享图带轻量品牌水印（如角落「拍立贴 · SnapStick」）；会员去水印。
- 分享是导出图片，**不需要后端 / 不生成可复现链接**（链接分享属未来范围，见 §9）。

### 5.5 会员

- **权益**：① 解锁全部会员专属相纸；② 无限每日配额；③ 分享去水印。
- **实现**：本地会员标志，由 `MembershipService` 统一提供；UI 只读 `isMember`。开发期可用调试开关，上线用 StoreKit2 订阅（收据校验在设备本地完成，无需自建服务器、无需账户登录）。
- **订阅引导入口**：配额用尽提示、会员相纸锁标、（可选）设置页。具体定价 / SKU 待定。

## 6. 数据模型与持久化

- **`PaperStyle`（新增，代码常量目录）**：`id: String`、`name: String`、`isPremium: Bool`、视觉参数。提供 `PaperCatalog.all` / `PaperCatalog.default` / `PaperCatalog.style(for:)`。
- **`PhotoRecord`（扩展）**：新增 `paperStyleID: String`（默认 `"cream"`）。`PhotoStore` 的 `index.json` 增加该字段，**做向后兼容**：旧记录缺字段时回落到默认。
- **配额状态（UserDefaults）**：`paper.usedToday: Int`、`paper.lastResetDay: String`。
- **会员状态**：本阶段本地标志（具体存储随 StoreKit 占位实现而定，不进 `index.json`）。
- **新增 service（纯本地实现）**：
  - `QuotaService`：`remaining`、`canConsume`、`commitConsume()`（AI 成功后调用）、`reset(ifNeeded)`。
  - `MembershipService`：`isMember`、`purchase()` / `restore()`（StoreKit2，本地收据校验）。

## 7. UI / 交互要点

- **相机主界面**：常驻「今日剩余 N/10」轻量计数；会员显「∞」；用尽时变会员引导入口。
- **结果页**：底部加横向相纸选择器（缩略图条）+ 「分享」按钮；会员相纸带锁标。
- **配额用尽**：拦在快门前，弹提示「今日相纸已用完，明天再来或开通会员」+ 引导。
- **会员引导**：轻量底部弹层，说明权益（专属相纸 / 无限配额 / 去水印）。
- 文案全部中文；视觉沿用 `Palette`，不引入新色值来源；遵守设计约束（无拍立得商标元素）。

## 8. 边界与异常

- AI 失败 / 网络错误：不扣配额，保留原照片 + 错误提示（沿用现有「流程总会完成」原则）。
- 配额为 0 时按快门：直接拦截，不发起 AI 调用。
- 改系统时间 / 重装绕过配额：纯本地记账的已知局限，接受（详见 §5.1）。
- 旧历史记录无 `paperStyleID`：回落默认相纸。
- 免费用户预览会员相纸：可预览，不可确认 / 分享，引导订阅。

## 9. 不做的范围（Non-goals，本期）

- **不做账户体系，不做任何后端 / 服务端**（配额、会员全在设备本地）。
- 不做可复现的链接 / 码分享（仅导出图片）。
- 相纸不影响 AI 风格、不影响沙盒物理 / 音效（仅外观）。
- 不做相纸的内购单买 / 集换（仅区分免费 vs 会员）。
